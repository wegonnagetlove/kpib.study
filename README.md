# 104 КПИБ · рабочий стол группы

Сайт группы 104 КПИБ (ВШГА МГУ, кафедра компьютерного права и информационной безопасности) в формате ленты соцсети. Собран из Craft-документа «Рабочий стол группы» и работает на GitHub Pages без сервера и без сборки.

**Что внутри**

- **Лента**: объявления, ДЗ с дедлайнами, новые конспекты, посты канала «Компы Важное», подборка конференций. Под постами «Обсудить» (беседа группы в Telegram), «Сохранить», «Поделиться». Всё, что появилось с прошлого визита, помечено «новое», есть вкладка «Новое» и счётчик на «Ленте»; длинные посты свёрнуты. Кружки дисциплин с красной цифрой: есть свежие непрочитанные конспекты.
- **Профиль**: при первом заходе сайт предлагает выбрать себя из списка группы; дальше слева «Мой профиль и баллы», в сообществах «Мои баллы». Выбор, сохранённое и прочитанное хранятся в браузере.
- **Тёмная тема**: включается по настройке телефона; вручную слева внизу или в «Участниках» → «Оформление».
- **Сообщества дисциплин**: карточка курса (преподаватель, время, часы, итог), материалы, конспекты по месяцам, рейтинг.
- **Конспекты**: все лекции из Craft с цветовой разметкой (определения, выводы, НПА, авторы), прогресс чтения, переход к следующей лекции.
- **Расписание**: неделя, занятия кафедры по датам, виджет «ближайшие пары» с отметкой «идёт сейчас».
- **Участники**: страница каждого студента с баллами по кафедральным дисциплинам из таблиц «Рейтинг» и порогами 70, 100, 110, 120. Кнопка «Это я» запоминает выбор в браузере и показывает «Мои баллы» в сообществах.
- **Баллы БРС** (`#/calc`): калькулятор БРС из папки `brs/` (журнал из таблицы «БРС-для-сайта», заявки, прогноз, PDF-отчёт). Старый адрес brs-kpib.tatnet.app переадресует сюда. Подборка мероприятий: `brs/events.html`.
- **Конференции и НИР**: 40 мероприятий с фильтрами по профилю и дисциплине, баллы, сроки заявок.
- **ДЗ, БРС, ВКР, контакты и беседы**, поиск по всем конспектам (клавиша `/`).
- **Почта группы** по ссылке.
- **Уведомления на телефон** (`#/notify`): пуши через ntfy со звуком «аськи» (на Android), утренняя и вечерняя сводка.
- **Календарь** `calendar.ics`: пары по расписанию ВШГА, дедлайны и подходящие конференции. Подписка со страницы «Расписание», обновляется сама.

## Как писать лекции и добавлять информацию

Всё пишется в Craft, в документе «Рабочий стол группы». Сайт подтягивает его раз в час (Actions → «Craft → сайт»), токен GitHub не нужен.

- **Лекции, ДЗ, БРС, ВКР, дисциплины:** кнопка «Редактировать в Craft» на странице сайта открывает нужное место в Craft.
- **Новая лекция:** «+ Новая лекция в Craft» в сообществе дисциплины, страница с названием «Лекция от …».
- **Объявления и дедлайны:** лента берётся из канала «Компы Важное» и `data/posts.json`.

## Публикация

1. Settings → Pages → Build and deployment: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
2. Через минуту сайт откроется по адресу `https://wegonnagetlove.github.io/kpib.study/`.
3. Settings → Secrets and variables → Actions → Variables: `SITE_URL` с этим адресом (ссылка в Telegram-сводке).

Локально: `python3 -m http.server` в папке репозитория и открыть `http://localhost:8000`.

## Сводки и пуши: время

GitHub запускает задачи по расписанию с опозданием, иногда на несколько часов. Поэтому сводка «пары и дедлайны» стартует несколько раз в каждом окне, а скрипт `scripts/digest_run.py` смотрит на московское время: утренняя «Сегодня» уходит только с 06:00 до 12:00, вечерняя «Завтра» только с 17:00 до 23:30, каждая не больше раза в день (`data/digest_sent.json`). Пуши о новых постах с 23:30 до 07:30 не отправляются и уходят утром.

## Проверка ссылок

Каждый день в 04:23 МСК workflow «Проверка ссылок» открывает все внешние ссылки сайта и пишет результат в `data/links.json`. Мёртвые ссылки (404, удалённые формы, недействительные приглашения) сайт не показывает: кнопки убираются, ссылка в тексте становится обычным текстом, строка из одной такой ссылки убирается целиком. Сайты, которые не пускают проверку с зарубежных серверов, считаются рабочими.

## Синхронизация с Craft

Workflow `.github/workflows/craft.yml` каждый час забирает документ «Рабочий стол группы» через Craft API и запускает `scripts/import_craft.py`. Правки в Craft появляются на сайте в течение часа (плюс 1–2 минуты на публикацию).

1. В Craft: Connections → API Connection с документом «Рабочий стол группы», Permission Level: Read Only.
2. Скопировать URL подключения (строка URL) и сохранить в Settings → Secrets and variables → Actions → **New repository secret** с именем `CRAFT_API_URL`.
3. Actions → «Craft → сайт» → Run workflow, чтобы обновить сразу.

Пока секрета нет, задача ничего не делает. Если выгрузка пришла явно неполной (страниц стало меньше вдвое), изменения не сохраняются.

Ссылки на файлы `r.craft.do/…`, которые выдаёт Craft API, временные и через несколько часов перестают открываться. Поэтому импорт сразу скачивает каждый файл в `assets/files/<хэш>/<имя файла>` и ставит на сайте постоянную ссылку; одинаковые файлы не дублируются. Если файл скачать не удалось, ссылка ведёт на опубликованную страницу Craft.

## Конспекты в PDF и Word

На странице лекции и разделов ДЗ, БРС, ВКР кнопки **PDF** и **Word**. PDF открывается в окне печати браузера (выбрать «Сохранить как PDF»), текст остаётся текстом. Word собирается прямо в браузере (`assets/export.js`, JSZip с cdnjs) в настоящий .docx. Оформление: белый фон, Google Sans, межстрочный 1,25 без отступов до и после, цветные выделения как на сайте. Имя файла ЧТО=КТО=ГГММДД, например `ФилПр=БЮМ=261006`.

## Расписание ВШГА

Workflow `.github/workflows/tt.yml` каждые 3 часа забирает расписание группы 104кпиб с [tt.audit.msu.ru](https://tt.audit.msu.ru/time-table/group?type=0) (с прошлой недели на 10 недель вперёд) в `data/tt.json`. По нему сайт строит пары на каждый день. Занятия кафедры из `data/schedule.json` (отмены и переносы из канала) имеют приоритет. Если сайт ВШГА недоступен, остаются последние сохранённые данные, а за пределами их дат действует недельная сетка.

## Почта группы

Почта открывается по ссылке (значок письма в шапке, виджет справа, «Контакты»): https://e.mail.ru/inbox/. Сайт ящик не читает.

## Канал «Компы Важное»

Посты канала идут в ленту (вкладка «Компы Важное») и в виджет справа, с картинками и ссылкой на пост.

1. Создать бота (см. ниже) и добавить его в **администраторы** канала. Права можно снять все.
2. Опубликовать в канале любой пост.
3. Actions → «Канал «Компы Важное» → сайт» → Run workflow. В логе будет строка `канал: -100… Компы Важное`. Этот id записать в Variables как `TG_CHANNEL_ID`.

**Сейчас автозапуск выключен**: секрет `TG_BOT_TOKEN` не задан, и workflow ничего не делал. После шагов 1–3 верните в `channel.yml` расписание (строки закомментированы в начале файла). До этого новые посты канала добавляются вручную в `data/telegram.json`.

Дальше workflow каждые полчаса забирает новые и отредактированные посты. Telegram хранит их для бота 24 часа, поэтому посты, вышедшие до подключения бота, сами не подтянутся: их можно добавить постами на сайте. Публиковать только посты с тегом (например `#сайт`): переменная `TG_FILTER_TAG`. Не сохранять картинки в репозиторий: `TG_SAVE_PHOTOS=0`.

Канал закрытый, а сайт публичный: всё, что попадает в ленту, видно по ссылке на сайт любому.

## Telegram-бот и сводки

1. В @BotFather: `/newbot`, получить токен.
2. Добавить бота в беседу «Группа без преподавателей» и написать туда любое сообщение.
3. Secrets: `TG_BOT_TOKEN` с токеном.
4. Actions → «Telegram-сводка» → Run workflow с режимом `chats`: в логе будет `chat_id` беседы (у групп он отрицательный, например `-1001234567890`). Сохранить его в секрет `TG_CHAT_ID`.

После этого бот:

- в 08:40 МСК (пн–сб) присылает пары на сегодня и дедлайны на три дня;
- в 20:10 МСК присылает, что завтра.

Без бота эти же сводки всё равно приходят пушем через ntfy (см. «Уведомления на телефон» на сайте).

Если в беседе включена приватность бота (по умолчанию), шаг 2 всё равно сработает: бот видит сообщения, адресованные ему, и событие добавления в группу.

## Как обновлять

Удобнее всего через редактор на сайте (выше). Вручную тоже можно.

**Новое объявление или ДЗ**: дописать запись в `data/posts.json` (поля `date`, `author`, `text` в markdown, `deadline` или `deadlines`, `tags`, `pinned`, `done`). `author`: код дисциплины (`apip`, `pvdi`, `proi`, `filpr`, `ptgp`, `iop`, `krr`, `eng`), «Учебный отдел» или «Кафедра».

**Расписание**: `data/schedule.json`, раздел `department` содержит занятия кафедры по датам и имеет приоритет над недельной сеткой.

**Конспекты, рейтинги, мероприятия из Craft**: выгрузить документ из Craft (`blocks get <id> --format markdown --depth 6`) в файл и запустить

```
python3 scripts/import_craft.py craft_export.txt
```

Скрипт пересоздаёт `content/` и `data/tree.json`, `data/tt.json             официальное расписание с tt.audit.msu.ru (обновляет Actions)
data/events.json`. Лекции, написанные в редакторе сайта, сохраняются (если та же лекция есть и в Craft, остаётся версия с сайта). Правки разделов и страниц дисциплин, сделанные на сайте, импорт перезапишет текстом из Craft. Пароли из текста вырезаются автоматически. Файл выгрузки в репозиторий не коммитится (`.gitignore`).

## Структура

```
index.html               оболочка приложения
assets/app.js            маршруты, лента, виджеты, рейтинг, поиск
assets/md.js             markdown-рендер под разметку Craft
assets/app.css           стиль (палитра #4285F4 #EA4335 #FBBC04 #34A853)
data/group.json          группа, контакты, беседы, студенты, пороги БРС
data/schedule.json       дисциплины и расписание
data/posts.json          объявления и ДЗ
data/events.json         конференции и конкурсы (из Craft)
data/tree.json           оглавление конспектов (из Craft)
data/telegram.json       посты канала «Компы Важное»
data/tt.json             расписание с tt.audit.msu.ru (обновляет Actions)
data/notified.json       что уже отправлено пушем
calendar.ics             календарь для подписки (собирает Actions)
assets/notify.js         страница уведомлений, звук на открытом сайте
assets/sounds/aska.mp3   звук уведомлений
sw.js                    service worker для уведомлений (ничего не кэширует)
brs/                     калькулятор БРС и подборка мероприятий
assets/uploads/          картинки из канала
content/pages/*.md       разделы рабочего стола
content/subjects/<код>/  страницы дисциплин, лекции, рейтинги
scripts/                 импорт Craft, расписание ВШГА, канал, сводки, пуши, календарь
```

Баллы на странице участника считаются по таблицам «Рейтинг» на дату импорта и носят справочный характер.
