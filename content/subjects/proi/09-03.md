## Военные предпосылки

<mark class="hl-cyan">**1957**</mark> — первый спутник в сочетании с атомной бомбой грозил военной катастрофой: ответные действия предполагали необходимость доведения приказов до исполнителей. Линии связи носили централизованный характер (коммутаторы) — возникла задача создания <mark class="hl-green">**удароустойчивой системы связи, сохраняющей способность к функционированию при утрате любого фрагмента или даже многих фрагментов**</mark>. Задачу Министерство обороны США поставило перед Агентством перспективных научных проектов (**ARPA**; DARPA впоследствии стала департаментом МО США).

## Математический фундамент: теория графов

<mark class="hl-yellow">**Теория графов**</mark> — раздел математики, изучающий свойства графов (<mark class="hl-purple">Л. Эйлер</mark>, <mark class="hl-blue">1736)</mark>. Граф — множество вершин, соединённых рёбрами; ребро — ненаправленная линия, дуга — направленная; ориентированный граф — множество вершин, соединённых дугами; путь в графе — последовательность вершин, в которой каждые две соседние соединены ребром (основа **маршрутизации**). <mark class="hl-green">**Сеть — граф, в котором вершины («узлы») соединены по принципу «многие ко многим» и помечены (несут смысловую нагрузку)**</mark>.

## Хронология создания интернета

| **Год** | **Событие** |
| --- | --- |
| **1961** | студент MIT Леонард Кляйнрок — технология пакетной коммуникации; Дж. Ликлайдер — концепция «Галактической сети» |
| **1962** | Ликлайдер возглавил компьютерное направление в DARPA |
| **1964** | RAND Corporation предложила децентрализованную систему из независимых сегментов (tatters — «куски») |
| **1965** | эксперименты по объединению компьютеров |
| **1969** | 2 сентября (29 октября) — **ARPANet** (первый сеанс: log-in) |
| **1971** | Р. Томлинсон — электронная почта и знак @ (коммерческое «эт»; арроба ≈ 12 кг) |
| **1972** | международная конференция — презентация сети ARPANET; архитектура создавалась неформальной группой учёных — не по военному и не по коммерческому заказу (В. Серф (IBM), Р. Кан (AT&T Bell Labs)) |
| **1974** | **создан протокол TCP/IP** (Transmission Control Protocol / Internetworking Protocol): TCP — протокол разбиения сообщения на пакеты, IP — протокол межсетевого взаимодействия; Internet — изначально название программы Interconnected Network («сеть между сетями») |
| **1976** | Р. Меткалф — Ethernet |
| **1983** | разделение MilNet и ARPANet |
| **1986** | Национальный фонд науки США (NSF) — NSFNet: пропускная способность выше, чем у ARPANET; коммерческое использование не допускалось |
| **1990** | 28 февраля — сеть ARPANET прекратила существование |
| **1991** | Европейская физическая лаборатория — протокол World Wide Web (www) и первый web-сервер |
| **1993** | Тим Бернерс-Ли — технология всемирной паутины, язык гипертекстового документа HTML, уникальный электронный адрес URL |
| **1995** | 30 апреля — NSFNET расформирована, коммерческий сегмент стал основным; интернет включал 22 тыс. иностранных сетей, включая российский сегмент |

<mark class="hl-yellow">**Протокол**</mark> — набор семантических (смысловое значение) и синтаксических (функциональное взаимодействие) правил, определяющих поведение систем, выполняющих логически связанные группы функций при передаче данных, — процедурная характеристика; логическая характеристика протокола = структура (формат) + содержание (семантика) сообщений. <mark class="hl-green">**Логика функционирования сети определяется протоколами**</mark>: тип и структура сообщений, процедуры обработки, генерация сообщений, реакция на сообщения.

## Четыре периода эволюции интернета

| **Период** | **Характеристика** |
| --- | --- |
| **Первый (1969–1990)** | 1969 — ARPANet; 1974 — TCP/IP, начало интернета; 1983 — ARPANet/MilNet; 1990 — ARPANet/NSFNET; некоммерческая направленность, управление — госструктуры США |
| **Второй (до 1995)** | электронная почта + передача файлов + текстовый интерфейс; поиск информации по точному адресу — поисковых систем не было; персональные компьютеры; 1993 — «Всемирная паутина» (перекрёстные ссылки), HTML; 1995 — NSFNET расформирована |
| **Третий (1995–2020)** | CERN — WWW; графический интерфейс; интернет = средство общения + источник информации; коммерческая сеть, эпоха цифровой коммерции, новые виды компаний; новые сети — 2004 (например, Gloriad) |
| **Четвёртый (с 2020-х)** | заполнение интернета синтетическим контентом, произведённым ИИ; «захват интернета ботами»: **2024 — автоматизированный трафик впервые обошёл человеческий**; 2025 — около 40% новых сайтов создавались с помощью ИИ, 20% полностью сгенерированы без участия человека; вытеснение поисковиков и сайтов искусственным интеллектом |

## Четвёртый период: контент ИИ и «мёртвый интернет»

Интернет наполняется и замусоривается контентом, сгенерированным ИИ. Приход **больших языковых моделей** может сконцентрировать власть над онлайн-знанием в руках техногигантов; сеть переполняется низкопробными сайтами на основе поисковой оптимизации, плагиатом и сайтами, созданными для политического влияния. Потеря глубины и разнообразия: рост ИИ-контента ведёт к дефициту оригинальных идей и разнообразия мнений. ИИ лучше человека справляется с генерированием текстов, и его продукция вызывает больше доверия — несмотря на *«галлюцинации»* и недостоверную информацию; тексты нередко выглядят «подчищенными» и ненатурально жизнерадостными. <mark class="hl-cyan">**Теория мёртвого интернета постепенно превращается в реальность**</mark>.
